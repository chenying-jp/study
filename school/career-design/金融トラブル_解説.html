PDF 89枚目まいめ
金融きんゆうトラブルや悪質あくしつな詐欺さぎに遭あわないための、最もっとも基本きほん的で大切たいせつな心構こころがえは？
✅ 正解せいかい
「ローリスク・ハイリターン（おいしい話はなし）」は世よの中なかに存在そんざいしないと理解りかいしておく

📖 知識ちしきポイント（簡単かんたんに説明せつめい）

ローリスク・ハイリターン = 「危あぶないことは少すくないのに、儲もうけは大おおきい」
→ 日本語で言うと 「おいしい話はなし」 です。

でも、現実げんじつの世界せかいでは、こんな話はなしは ほとんどありません。
儲もうける可能性かのうせいが高たかいほど、危険きけんも大おおきくなります。

🔍 解とき方かたの考かんがえ方かた

  1. 「最もっとも基本きほん」→ PDFの最初さいしょのポイント①を探さがす
  2. PDF：「おいしい話はなしには気きをつける」
  3. 「友ともだちが勧すすめたから安全あんぜん」→ ❌ 友ともだちでも騙だまされることがある
  4. 「断ことわると失礼しつれい」→ ❌ 怪あやしければ断ことわるべき
  5. 「一人ひとりで耐たえる」→ ❌ 相談そうだんすることが大切たいせつ
PDF 91枚目まいめ
「ポンジ・スキーム」で、被害者ひがいしゃが詐欺師さぎしを信頼しんらいしてしまい、さらに大金たいきんを騙だまし取とられやすいのはなぜ？
✅ 正解せいかい
最初さいしょは実際じっさいに配当金はいとうきん（お金かね）が支払しはらわれるから

📖 知識ちしきポイント

ポンジ・スキーム（ポンzi 詐欺さぎ） とは：
→ 新あたらしい人ひとから集あつめたお金かねで、古ふるい人ひとに配当はいとうを払はらう仕組しくみ。
→ 本当ほんとうは儲もうけていないのに、「儲もうかっている振ふり」をします。

最初さいしょの数すう回かいは、本当ほんとうにお金かねが入はいる！
→ 「本物ほんものだ！」と思おもって、もっと大おおきな金かねを投とうずる。
→ その後あと、詐欺師さぎしは逃にげてしまう。

🔍 解とき方かた

  1. ポンzi詐欺さぎの特徴とくちょう②を覚おぼえる
  2. 「国くにの証明書しょうめいしょ」→ ❌ 偽造ぎぞうもある
  3. 「元本がんぽん100%返金へんきん」→ ❌ そんな話はなしはない
  4. 「最初さいしょにお金かねが入はいる」→ ✅ PDFの説明せつめいと一致いっち
PDF 92枚目まいめ
ポンジ・スキームなどの大おおきな詐欺さぎについて注意ちゅういすべき点てんとして正ただしい説明せつめいは？
✅ 正解せいかい
テレビ番組ばんぐみで「流行りゅうこうの副業ふくぎょう」などと取とり上あげられていても、それだけで安全あんぜんの保証ほしょうにはならない

📖 知識ちしきポイント

詐欺さぎの会社かいしゃも、有名人ゆうめいじんやテレビを使つかいます。
でも、「テレビに出でた = 安全あんぜん」ではありません。

詐欺さぎの形かたちも色々いろいろ：
・投資とうし（とうし）
・和牛わぎゅうのオーナー制度せいど
・金きんの製品せいひんを買かうだけ、など

🔍 解とき方かた

  1. 「100%信頼しんらいできる」→ ❌ 絶対ぜったいに言いわない
  2. 「テレビ = 安全あんぜんではない」→ ✅ PDFと同おなじ
  3. 「投資とうし信託しんたくだけ」→ ❌ 形かたちは色々いろいろ
PDF 93枚目まいめ
借金しゃっきんの返済へんさいに困こまり、別べつの金融機関きんゆうきかんからさらに借金しゃっきんを重かさねて、雪ゆきだるま式しきに負債ふさいが増ふえる状態じょうたいを何なんと呼よぶ？
✅ 正解せいかい
多重債務たじゅうさいむ

📖 知識ちしきポイント

多重たじゅう債務さいむ（たじゅうさいむ）= 複数ふくすうの場所ばしょから借金しゃっきんをして、返かえせなくなる状態じょうたい

例れい：
A社しゃから借かりる → 返かえせない → B社しゃから借かりる → さらに増ふえる…
= 雪ゆきだるまのように大おおきくなる ❄️

他ほかの選択肢せんたくし：
・カントリーリスク = 国くにの危険きけん
・ドルコスト平均法へいきんほう = 投資とうしの方法ほうほう
・ポータビリティ = 携帯けいたい性せい（関係かんけいない）
PDF 94枚目まいめ
SNSやネット掲示板けいじばんで個人こじんを装よそおって接触せっしょくしてくる「ヤミ金融きんゆう」について正ただしい説明せつめいは？
✅ 正解せいかい
違法いほうな高金利こうきんりを要求ようきゅうされるだけでなく、自分じぶん自身じしんや会社かいしゃ、家族かぞくへも暴力的ぼうりょくてき・脅迫的きょうはくてきな取とり立たてが行おこなわれる恐おそれれがある

📖 知識ちしきポイント

ヤミ金融きんゆう = 法律ほうりつを守まもらない違法いほうな貸かし金かね業者ぎょうしゃ

⚠️ 注意ちゅうい：
・金利きんり（利息りそく）が法律ほうりつの上限じょうげん（20%など）を超こえる
・SNSで「#お金かね貸かします」と個人こじんを装よそおうことも多おおい
・自分じぶんだけでなく、家族かぞくや会社かいしゃにも脅おどし取とり立たてがある

✅ 確認かくにん方法ほうほう：金融庁きんゆうちょうの「登録とうろく貸金かしきん業者ぎょうしゃ情報じょうほう検索けんさくサービス」
PDF 97枚目まいめ ①
「闇やみバイト」で免許証めんきょしょうや学生証がくせいしょう、家族かぞく構成こうせいなどを送おくらせる本当ほんとうの狙ねらいは？
✅ 正解せいかい
危険きけんな犯罪はんざい行為こういだと気きづいて途中とちゅうで「辞やめたい」と言いい出だしたときに、脅迫きょうはくして逃にげられないようにするため

📖 知識ちしきポイント

闇やみバイト = 見みた目めは簡単かんたんな仕事しごとだが、実じつは詐欺さぎや強盗ごうとうなどの犯罪はんざい

「日給にっきゅう5万円まんえん！簡単かんたん！」→ とても怪あやしい ⚠️

個人情報こじんじょうほう（免許証めんきょしょう・住所じゅうしょ・家族かぞく）を知しられると：
→ 「家族かぞくを狙ねらうぞ！」「逃にげられないぞ！」と脅おどされる
→ 辞やめられなくなる
PDF 97枚目まいめ ②
「闇やみバイト」に加担かたんして犯罪はんざいが警察けいさつに発覚はっかくしたとき、実際じっさいにどうなる？
✅ 正解せいかい
犯罪はんざいの指示しじを出だしている組織そしきの上層部じょうそうぶの身代みがわりとして、応募おうぼした実行犯じっこうはんだけが逮捕たいほされ、捨すて駒ごまにされる

📖 知識ちしきポイント

捨すて駒ごま（すてごま）= 組織そしきが自分じぶんを守まもるために、下したの人ひとだけ罪つみにする

❌ 「脅おどされていたから無罪むざい」→ 必かならずしも無罪むざいにはならない
❌ 「厳重注意げんじゅうちゅういだけ」→ 逮捕たいほされることも多おおい
❌ 「組織そしきが守まもってくれる」→ 逆ぎゃくに捨すてられる
PDF 98枚目まいめ
日本から海外かいがいのオンラインカジノサイトにアクセスして賭かけをする行為こういについて正ただしい説明せつめいは？
✅ 正解せいかい
日本国内こくないからアクセスしてオンラインカジノで賭かけを行おこなうことは「賭博罪とばくざい」などの犯罪はんざいにあたる

📖 知識ちしきポイント

オンラインカジノ = スマホやPCでカジノ遊あそびをするサイト

⚠️ 重要じゅうよう：
・海外かいがいで合法ごうほうでも、日本から使つかう = 犯罪はんざい
・「無料版むりょうばん」や「無料むりょうボーナス」もダメ
・SNSで紹介しょうかいするのも犯罪はんざい

罰ばつ：賭博罪とばくざい → 50万円まんえん以下いかの罰金ばっきん
